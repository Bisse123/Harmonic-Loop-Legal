# Harmonic-Loop-Legal

The Harmonic Loop website, hosted on GitHub Pages at https://bisse123.github.io/Harmonic-Loop-Legal/.

- `index.html` is the home page.
- `privacy-policy.html` and `terms-of-service.html` are written by the game's **Tools > Export Legal
  Documents** (`Assets/_GAME/Editor/Guides/LegalDocumentExporter.cs`) from `LegalDocuments.cs`.
  Export them into this folder rather than editing them here.
- `assets/` holds the shared stylesheet and script, the Barlow font (SIL Open Font License, see
  `assets/fonts/Barlow-OFL.txt`) and the images, taken from the game's store listing and icons.
