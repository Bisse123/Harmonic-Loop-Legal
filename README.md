# Harmonic-Loop-Legal

The Harmonic Loop website, hosted on GitHub Pages at https://bisse123.github.io/Harmonic-Loop-Legal/.

- `index.html` is the home page.
- `privacy-policy.html`, `terms-of-service.html` and `delete-account.html` are written by the game's **Tools >
  Export Legal Documents** (`Assets/_GAME/Editor/Guides/LegalDocumentExporter.cs`) from `LegalDocuments.cs` and
  `AboutInfo.cs`, straight into this folder when it sits beside the game's repository. Export them rather than
  editing them here.
- `assets/` holds the shared stylesheet and script, the Barlow font (SIL Open Font License, see
  `assets/fonts/Barlow-OFL.txt`) and the images, taken from the game's store listing and icons. The export
  also rewrites `assets/img/logo.png`, `assets/img/app-icon.png` and the font files from the game's own.
